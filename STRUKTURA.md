🎓 ЯК РОЗШИРИТИ ПРОЕКТ
═════════════════════════════════════════════════════════════════════════════

1. Додавання нової вправи:
   ExerciseService.add({ name: "Мертва тяга", category: "back" });

2. Додавання нового продукту:
   FoodService.addCustom({ name: "Рибань", calories: 200, protein: 30, ... });

3. Слухання события:
   EventBus.on('workout-completed', (data) => { console.log(data); });

4. Випуск события:
   EventBus.emit('achievement-unlocked', { achId: 'first_workout' });
