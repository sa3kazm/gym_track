# Програма: лог, редагування, прогрес, експорт

## Логування тренувань
- Кнопка **«Завершити з логом»** на картці
- Введіть вагу (кг) і повтори для кожного підходу
- Зберігається в `WorkoutSession` (Prisma) + обсяг (кг×повтори)

## Редагування
- **«Редагувати»** під кожною вправою (до завершення)
- Змінити підходи, повтори, RPE, відпочинок
- Замінити вправу з бібліотеки

## Прогрес
- Графік **% виконаних** тренувань по тижнях на `/program`

## Експорт
- **Календар (.ics)** — імпорт у Google Calendar / Outlook
- **PDF / Друк** — `/program/print` → «Зберегти як PDF» у діалозі друку
