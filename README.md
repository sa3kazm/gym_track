# 💪 Gym & Nutrition Tracker

Розумний щоденник тренувань та харчування з адаптивним дизайном у стилі фітнес-додатків.

## 🚀 Швидкий старт

### Без установки (найпростіше)
1. **Завантажи файли** в папку `gym-tracker/`
2. **Відкрий `index.html`** у браузері
3. **Готово!** Додаток почне працювати локально

### З локальним вебсервером (рекомендується)
```bash
# Python 3
python -m http.server 8000

# Або Node.js (http-server)
npx http-server

# Потім відкрити: http://localhost:8000
```

## 🎮 Як користуватися

### 1️⃣ **Профіль** (перша сторінка)
- Введи ім'я, вік, зріст, поточну вагу
- Встанови цільову вагу та ціль (схуднення/набір/підтримання)
- Оновіть денні норми КБЖУ (розраховуються автоматично за формулою)

### 2️⃣ **Тренування**
- **Конструктор**: Створи програму (ППЛ, ЮPPER/LOWER і т.д.)
- **Щоденник**: Логуй кожний підхід (вага × повтори)
- **Таймер**: Натисни "Старт" — буде звуковий сигнал по закінченню

### 3️⃣ **Їжа**
- Пошукай продукт у базі (введи назву)
- Вибери кількість грамів
- Прогрес-бари оновляться автоматично

### 4️⃣ **Прогрес**
- 📈 **Графіки** ваги (крива за місяц)
- 💪 **Статистика** — всього тренувань, обсяг
- 🏆 **Ачівки** — розблокуються автоматично

## 🔧 Архітектура даних

### LocalStorage ключі
```javascript
gnt_profile               // Профіль користувача
gnt_programs              // Програми тренувань
gnt_exercise_library      // Бібліотека вправ
gnt_workout_log           // Щоденник тренувань
gnt_nutrition_log         // Щоденник їжі
gnt_food_database_custom  // Додані користувачем продукти
gnt_water_log             // Трекер води
gnt_achievements          // Ачівки та стріки
```

### Як розширити на API?
`storage.js` — усі операції йдуть через методи (get/set). Щоб переходити на сервер:

```javascript
// Замість:
const data = _storage.get(key);
localStorage.setItem(key, JSON.stringify(data));

// Стає:
const data = await fetch(`/api/${key}`).then(r => r.json());
await fetch(`/api/${key}`, { method: 'POST', body: JSON.stringify(data) });
```

**Жоден інший файл не потребує змін!**
